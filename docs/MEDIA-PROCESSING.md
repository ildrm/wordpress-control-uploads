# Local media processing

These optional paths are implemented and tested with harmless fixtures. They are not a claim of complete document security, whole-video detection, ML accuracy or production acceptance. Settings flags default to false. Configure absolute executable paths in deployment, then enable the corresponding feature in Settings or Setup. Never accept executable paths from an uploader or a REST request.

| Feature | Deployment variables | Bounds and behavior |
|---|---|---|
| PDF page inspection and reconstruction | `CF_PDFINFO_BIN`, `CF_PDFTOPPM_BIN`, `CF_PDFTOTEXT_BIN` | Poppler reports structure, all pages render at at most 2048 pixels on the longest side, pages are validated and freshly JPEG-encoded. A new image-only PDF preserves page sizes and contains no imported objects, attachments, forms, links or actions. Text extraction is ephemeral. |
| Video/audio processing | `CF_FFMPEG_BIN`, `CF_FFPROBE_BIN` | FFprobe measures duration/streams/dimensions. FFmpeg restricts demuxers and file/pipe protocols, samples bounded JPEG frames, reduces audio to mono 16 kHz MP3 clips of 30 seconds, and reconstructs accepted media without imported metadata/chapters. Output size, streams and duration are checked. |
| Offline Content Credentials | `CF_C2PA_BIN`, optional `CF_C2PA_TRUST_ANCHORS` | Requires exactly `c2patool 0.28.1`. Remote manifests and OCSP fetching are disabled; network hosts are empty. Optional trust anchors are a deployment-owned local PEM file. Signature/asset binding, trust and AI declarations are separate measurements. |
| Audio transcription | `CF_OPENAI_TRANSCRIPTION_KEY` | OpenAI `whisper-1`, multipart reduced MP3, verbose JSON. The key is separate from the moderation key. Transcript and language are normalized; text is evaluated in memory and never persisted. There is no residency guarantee or live-account acceptance. |

Processing defaults: `max_duration=300` seconds, `max_frames=12`, `max_pages=20`, `sampling=uniform`. Allowed ranges are 1–600 seconds, 1–32 frames and 1–100 pages. Sampling can be uniform, scene changes, or interval plus scene changes. These values are separate from upload-byte and pixel limits. Security Only uses local structural checks and reconstruction without content-provider requests. Policies requiring content inspect pages/frames through the configured image providers and audio clips through a transcription-capable adapter. Missing required evidence on any inspected page/frame/clip prevents automatic publication. Consensus requires two distinct adapters for each requested content field on each inspected page/frame. Distinct frames, local PDF text and transcript-only results cannot count as independent image-category evidence.

Processes receive an argument array without a shell, a minimal environment without inherited credentials, a private working directory, closed stdin, bounded output and deadlines. Native work and provider calls renew the owned queue lease. Temporary work expires after 24 hours following interruption. Local paths and native stderr are excluded from REST diagnostics and audit metadata.

This is not an OS sandbox. Run maintained tools as an unprivileged user with deployment-enforced network denial, memory/CPU/process/file limits and private temporary storage. The plugin limits individual FFmpeg allocations and threads; it does not establish a total OS memory bound. Poppler/native parsers and GD require security maintenance. Health checks configured paths and executable permissions; this does not detect a missing dynamic library or certify a tool's runtime behavior. Run the native acceptance fixtures on the actual worker host.

PDF publication flattens searchable text, forms, links and digital signatures. A provider finding on a rendered page is not a PDF redaction map. PDF/Office/temporal SANITIZE requests with no supported transform stay in review. Office conversion/CDR and archive reconstruction are not implemented; those files remain held even after human approval attempts. Raster previews are supported; document/video/audio previews are not.

Reconstructed public media does not preserve original Content Credentials. The moderation detail reports provenance of the retained private original only. An absent credential yields `provenance.present=0`; signature, signer trust and AI declaration remain unknown. AI declaration evidence is unknown if signature/asset binding is invalid. A verified AI declaration is an assertion, not a deepfake or AI-generation classifier. Unsupported MIME types yield no fabricated provenance evidence. Timestamp/revocation/network-dependent trust is not certified by offline verification.

Uniform and scene sampling inspect selected instants, not every frame or an entire video continuously. Quiet/no-transcript audio and incomplete provider coverage may require review. Transcription contracts have deterministic tests but no live account or multilingual quality benchmark. Temporal redaction, aligned transcript timestamps, diarization, authenticity/deepfake models and whole-asset localization/accuracy remain incomplete.

Repeatable benign fixtures: `tests/Integration/media-tools.php`, `processing.php` and `provenance-tools.php`. The first two require explicit native paths. The provenance fixture requires `CF_C2PA_BIN`, `CF_C2PA_UNSIGNED_FIXTURE` and `CF_C2PA_SIGNED_FIXTURE`; use independently verified official samples. No native binary, certificate private key, personal upload or malware corpus is distributed. See [release evidence](RELEASE-REPORT.md) for the versions actually executed.

Primary references: [FFmpeg documentation](https://ffmpeg.org/documentation.html), [FFprobe](https://ffmpeg.org/ffprobe.html), [c2patool](https://github.com/contentauth/c2patool), [C2PA settings](https://opensource.contentauthenticity.org/docs/rust-sdk/docs/context-settings/), [OpenAI transcription API](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create), [PHP process execution](https://www.php.net/manual/en/function.proc-open.php).

Real-file simulation shares this processing pipeline without creating a scan, attachment or publication job. It may invoke configured providers and report normalized summaries/costs, but deletes the privately copied sample/work and removes extracted words/codes from its response. Native failures return stable held/error outcomes. Simulation is an operator test, not a representative security/accuracy benchmark.

Lease renewal also participates in decision/publication transactions. A stale worker cannot commit evidence after losing ownership; a stale acknowledgement cannot revoke a committed accepted derivative. The ownership-change fixture forces those boundaries and complements independent claim/process-death tests. Native malformed JSON is classified at the native/provider boundary rather than mislabeled as a queue payload.
