# REST API

Namespace `content-firewall/v1`. WordPress cookie authentication requires its normal REST nonce; application-password requests use WordPress authentication. Nonces do not grant capabilities. Every endpoint has a permission callback. Blog context scopes all object reads.

| Endpoint | Method | Capability / behavior |
|---|---|---|
| /scans | GET | review queue; keyset `after`, bounded `limit`, optional state |
| /scans/{id} | GET | review queue; normalized evidence, no private path/key |
| /scans/{id}/preview | GET | reveal_sensitive_content; explicit safe raster derivative |
| /scans/{id}/action | POST | review queue; revision, action, required reason, explicit delete confirmation |
| /bulk | POST | review queue; ≤50 revision-bearing items, per-item results |
| /my-uploads | GET | authenticated read; own summarized records |
| /scans/{id}/appeal | POST | authenticated owner only; reason |
| /policy, /policies, /presets | GET | manage policies |
| /policy/save | POST | manage policies; immutable schema-1 snapshot |
| /simulation | POST | manage policies; synthetic signals/findings, no publication |
| /simulation/history | POST | manage policies; ≤100 retained scan records, no external requests |
| /analytics | GET | view analytics |
| /audit | GET | view audit; bounded cursor |
| /providers | GET | manage providers; capability/health metadata, no keys |
| /health, /settings | GET | manage firewall |
| /settings/save | POST | manage firewall; strictly permitted keys and limits |
| /library, /worker | POST | manage firewall; bounded background work |
| /network-policy | POST | manage_network_options; multisite snapshot |

Conflict/stale revisions return 409; unauthorized operations 403; absent records 404; validation/configuration errors expose stable codes with a generic message. Raw exception text, sensitive extracted text and provider authentication details are not responses.

For pending uploads, normal WordPress media endpoints return the upload gateway's private reference error rather than a public attachment. A custom headless upload/status endpoint and file-based simulator remain outstanding acceptance work. Machine-readable routes are generated by `tools/openapi.py` from controller route declarations.
