# Compatibility

Declared minimum: WordPress 6.8, PHP 8.2, MySQL 8 or MariaDB 10.11+. The queue requires SKIP LOCKED; publication requires InnoDB posts/postmeta. PHP must have fileinfo, JSON, mbstring and sodium. GD, DOM, ZIP, curl and native tools are feature dependencies. HTTPS, a persistent private root and a maintained worker/tool deployment are operational requirements. Exact executed versions and test scopes are centralized in [RELEASE-REPORT.md](RELEASE-REPORT.md); a configured CI matrix is not a completed result.

WordPress Media/AJAX/REST uploads and sideloads use covered prefilters. Authenticated multipart headless uploads use explicit WordPress/plugin limits and the private queue. Ordinary wp_insert_post saves, featured-media changes, supported legacy galleries/playlists and scheduled posts use the optional approval gate. Post content with supported attachment IDs is checked; arbitrary raw URL/custom shortcode/meta references, direct wp_publish_post/SQL writes, offload uploads and custom upload-action overrides still need explicit integration. Existing-library scanning is retrospective; an already public file can remain accessible before its held decision.

Blog tables/policies/scan/queue operations are tenant-scoped. Cached services are rebuilt for settings changes and guarded against active-blog mismatch. Network-enforced policy snapshots are immutable and override local policy; large-network provisioning is batched by CLI. Complete enterprise acceptance additionally needs central/network analytics, credential administration, large-network and third-party/offload fixtures.

Optional PDF and video/audio processing was tested with the versions in RELEASE-REPORT.md; supported media bounds are in MEDIA-PROCESSING.md. C2PA requires the pinned tool version, and the exercised macOS binary/fixtures do not imply native-tool acceptance on every deployment. Office/archive reconstruction, non-raster previews and temporal redaction are unavailable.

Sources: [WordPress upload flow](https://developer.wordpress.org/reference/functions/_wp_handle_upload/), [REST attachment controller](https://developer.wordpress.org/reference/classes/wp_rest_attachments_controller/), [post-save filter](https://developer.wordpress.org/reference/hooks/wp_insert_post_data/), [WordPress requirements](https://wordpress.org/about/requirements/), [plugin guidelines](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/).
